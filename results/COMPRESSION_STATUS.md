# 現状の到達点 — 結局どこまで圧縮できているのか

> **履歴**（2026-09-23 の索引 `results/INDEX.md` による）: 正規化レイヤー時代（09-18）の「到達点」。自前符号器 PCC2 より前の数値。**現在の数値は `results/standing.md`**。

測定日 2026-09-18。すべて C++ 実装（`cpp/build/pccnorm`）による実測で、
復元検証（可逆行はビット完全、誤差上限つきの行は宣言値を全点で遵守）を通している。

## 一言で

**「すでに圧縮済みのファイル」から、さらに 33〜42%。**
**「生の float32」からなら 85〜98%。**

この幅の大きさが要点である。削減率はアルゴリズムの強さではなく、
**元のファイルがどれだけ素朴な容器だったか**で決まっている。

### 2. 車載 LiDAR — KITTI drive_0001（108 フレーム / 1,318万点）

元は **生の float32 デカルト座標（無圧縮 .bin）**。

| 表現 | bpp | 元に対して |
|---|---|---|
| float32 デカルト 無圧縮 | 96.000 | — |
| 同 可逆圧縮（取得順差分 + zstd） | 46.183 | −51.9% |
| **極座標 2mm / 0.002° に量子化** | **14.184** | **−85.2%** |

最大再構成誤差 2.11 mm。HDL-64E の距離分解能が 2mm、測距精度が ±2cm なので、
**センサが保証している精度は一切損なっていない**。
ドライブ全体で 76.08 MB → 23.37 MB。108 フレーム全てで 14.065〜14.377 bpp と一貫。

### 3. 再構成形状 — Stanford Bunny / Dragon / Armadillo

元は **配布されている PLY**（Bunny と Dragon は ASCII テキスト）。

| モデル | 配布形式 | float32 可逆 | 点間隔/8 格子 | 配布に対して |
|---|---|---|---|---|
| Bunny (35,947点) | 675.0 bpp | 68.98 | **9.55 bpp** | **−98.6%** |
| Dragon (437,645点) | 618.4 bpp | 50.06 | **10.76 bpp** | **−98.3%** |
| Armadillo (172,974点) | 320.0 bpp | 74.89 | **6.50 bpp** | **−98.0%** |

配布形式だけで 3〜7 倍の無駄がある（ASCII テキスト）。
これは圧縮技術の成果ではなく、**容器の選択の問題**である。

## 何が効いたのか — 削減の出どころ

| 手段 | 効果 | 性質 |
|---|---|---|
| **容器の是正**（ASCII→binary、重複フィールドの除去） | 最大 −98%（Stanford）、−13.6%（AHN4） | 情報を一切捨てない |
| **センサ本来の量への復帰**（デカルト→極座標） | −69%（KITTI、可逆比） | 誤差はセンサ精度以下 |
| **精度要件の合意**（格子量子化） | 追加 −11〜18pt（AHN4） | 要件の決定であって圧縮ではない |
| 残差の相手選び + 差分 + レンジコーダ | −10.2pt（AHN4 可逆の 13.6→23.8） | 純粋な符号化の寄与 |
| 幾何の文脈モデル改良（点間隔以下） | 幾何の 4〜5% | **投資対効果が悪い** |

**純粋な符号化アルゴリズムの寄与は全体の半分以下**である。
残りは「そもそも何を送るべきか」という表現の問題だった。

## 残っているビットはどこにあるのか

AHN4 可逆 54.08 bpp の内訳（200万点標本）:

| | bpp | 割合 |
|---|---|---|
| 幾何 XYZ | 22.21 | **41.1%** |
| Reflectance | 9.77 | 18.1% |
| blue / nir / Deviation | 15.06 | 27.8% |
| green / red / intensity（外部） | 5.66 | 10.5% |
| gps_time / classification / その他 | 2.56 | 4.7% |

**幾何は 4 割しかない。** 点群圧縮の研究は幾何に集中しているが、
実データのビットの 6 割は属性が持っている。

幾何 22.21 bpp のうち、表面の形を述べているのは 11〜22%（*暫定 — 「表面」を
点間隔の格子と定義したことに依存する*）。残りは**レーザーがどこに当たったか**
という、世界について何も語らない情報である。

## 効かなかったもの（測って打ち切った方向）

| 方向 | 実測 | 理由 |
|---|---|---|
| 点間隔以下の文脈モデル | 幾何の 4〜5% | 点間隔以下に文脈が存在しない（H(c)=3.000） |
| 反復測量の差分符号化（AHN3→AHN4） | 幾何の 1.3% | 共有されるのは表面だけ。サンプリングは共有されない |
| ECT（Euler 標数変換） | D2 形状分布に 380 倍負ける | — |
| 位相（パーシステンス）による要件決定 | 13 データセットで一度も律速せず | センサ側の下限が常に 10〜40 倍きつい |

## この数字をどう読むか

- AHN4 の −23.8% と Stanford の −98% を並べてはいけない。**ベースラインが違う。**
- 可逆の行だけが「無条件に正しい」。格子の行は**精度要件を決めたこと**の結果であり、
  要件が違えば数字も変わる。圧縮率ではなく要件表として読むべきである。
- 最も移植性が高い成果は **AHN4 可逆 −23.8%** と **KITTI 極座標 −85.2%** の 2 つ。
  どちらも「元のファイルが持っていた無駄」を突いたもので、
  同種のデータには同じ理屈がそのまま効く。
