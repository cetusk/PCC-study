# 取得構造スコア

センサ由来の構造がどれだけ生き残っているかを測り、幾何表現の候補集合を絞る。

## 動機

サンプリング位置が幾何のビットの 78〜89% を占め、それを説明できるのは物体では
なく走査幾何である。そして「走査幾何が生きているか」は、複数の独立な指標で
同じものを測っていることが分かった。

| 指標 | 何を見るか |
|---|---|
| 第1近傍距離の変動係数 CV | 距離の規則性 |
| 接平面内の結合配向秩序 ψ6 | 角度の規則性 |
| 回転させたときの符号長 | 向きの特権性 |
| Morton に並べ替えたときの差 | 順序の意味 |
| 軸が固定格子に乗っているか | 走査軸の痕跡 |
| 方位角の単調性 | 回転走査の痕跡 |

## 設計方針

**スコアは判定を下さない。**候補集合を絞って試行時間を減らし、診断を出すだけで、
最終的な表現の選択は必ず実測で決める。幾何表現の判定は当たって +13%、
外して −174% という非対称性があるため、賭けてはいけない。

## 結果（5 データセット）

| データ | スコア | 格納順維持 | Morton候補 | 極座標候補 | 採用表現 | 時間 |
|---|---|---|---|---|---|---|
| Bunny 生スキャン | 0.66 | ✓ | — | — | grid | 0.1s |
| AHN4 航空LiDAR | 0.40 | ✓ | — | — | grid | 0.2s |
| KITTI 車載LiDAR | 0.38 | ✓ | — | **✓** | **polar/origin** | 0.2s |
| Stanford Armadillo | 0.18 | — | **✓** | — | grid | 0.2s |
| Stanford Bunny 再構成 | 0.15 | — | **✓** | — | grid | 0.1s |

**推奨は 5 データセットすべてで実測と一致した**（Morton の得失、極座標の可否）。
センサデータ 0.38〜0.66 / リメッシュ済み 0.15〜0.18 で、0.3 付近に切れ目がある。

## 実装時に潰した誤検出

**① 走査軸と格納格子の混同**
「軸が固定格子に 100% 乗っている」は AHN4 の z でも KITTI の z でも真だったが、
これは LAS の scale や既存の量子化であって走査軸ではない。区別は
**刻み / 点間隔** でつく。

```
Bunny 生 x : 624 段階、刻み 0.25mm、点間隔の 0.48 倍  → 走査軸
KITTI   z : 刻み 1mm、点間隔の 0.015 倍              → 格納格子
AHN4    z : 刻み 1mm、点間隔の 0.004 倍              → 格納格子
```

**② 遠い原点での方位角判定**
AHN4 は座標原点が広がりの 2110 倍遠いため、方位角がほとんど変化せず
「97% 単調」と出ていた。原点距離が広がりの 10 倍を超える場合は方位角判定を
無効にする。

**③ 微小な刻みでの整数判定の破綻**
刻みが細かいと `値/刻み` が巨大になり、倍精度の丸めで常に整数に見える。
`|値|/刻み > 1e9` の場合は判定しない。

**④ 回転の推奨を「ばらつき」で決めていた**
ばらつきが小さいことと回転が得であることは別。実際の利得
`(元の向き − 最良の回転) / 元の向き` で判断するよう変更した。
5 データセットすべてで元の向きが最良で、適当な向きより 3.1〜41.6% 良かった。
