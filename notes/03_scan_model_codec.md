# 走査モデル経由の幾何符号器（設計メモ）

測定の裏付けは `results/als_scan_structure.md`。要点は 3 つ。

- 掃引内の走査角は時刻の 1 次関数（残差 1.4 cm、幅 278 m）
- 掃引の点は厚さ 3.6 mm の鉛直面に乗る
- 発射番号は gps_time から決まるので、角度 2 自由度は副情報を生まない

0 次エントロピーで 25.248 → 17.308 bit/点（−31.4%、副情報込み）。

## 可逆性と決定性の要件

プロジェクトの規則は「外部符号化は整数のみ。浮動小数を使わない」である
（`notes/01_normalization_layer.md` 方針 4）。走査モデルは三角関数を含むので、
そのまま書くと処理系によって復号が破綻する。**`tan()` は libm 実装ごとに
最下位ビットが違う。** 次の 2 つで整数に閉じる。

### 1. 回転は 3 回のせん断で行う

掃引面の座標 $(s, \text{off})$ は $(X, Y)$ の回転である。任意角の回転は
整数の全単射ではないので、3 回のせん断に分解する。

$$R(\theta)=\begin{pmatrix}1&-\tan\frac\theta2\\0&1\end{pmatrix}
\begin{pmatrix}1&0\\ \sin\theta&1\end{pmatrix}
\begin{pmatrix}1&-\tan\frac\theta2\\0&1\end{pmatrix}$$

各せん断は $u \leftarrow u + \lfloor c\,v \rfloor$（$v$ は不変）の形なので、
丸め方によらず $\mathbb{Z}^2$ 上の全単射である。YCoCg-R と同じ理屈。
$\tan\frac\theta2$ と $\sin\theta$ は掃引ごとの**整数定数**として副情報に書く。
復号時に三角関数は呼ばない。

### 2. 走査角の正接は固定小数の表で引く

予測値 $s_{\text{pred}} = s_0 + (S_z - z)\tan(\theta_0 + \omega\,\Delta)$ の
$\tan$ は、$[-45°, +45°]$ を $2^{16}$ 分割した 32 bit 固定小数の表を
整数で線形補間して求める。符号化器と復号器が同じ表・同じ整数演算を使うので、
出力はビット単位で一致する。表は実装に埋め込む（副情報ではない）。

## ストリームの構成

符号器 id `C_GEOM_SCAN`（11）。担当する列は X, Y, Z の 3 つ。
gps_time と point_source_id は**先に復号されている必要がある**ので、
`plan_streams` はこの 2 列を幾何より前に置く（補助列の仕組みは幾何v2 と同じ）。

`param` に入るもの:

```
u8  版
u16 補助列の名前（gps_time）
u16 補助列の名前（point_source_id）
u32 掃引の数
掃引ごと（すべて整数・掃引をまたいで差分符号化）:
  基点 xm, ym            [scale 単位]
  せん断の定数 tan(θ/2), sin(θ)   [2^-30]
  s0                     [scale 単位]
  Sz                     [scale 単位]
  θ0                     [2^-32 回転]
  ω                      [2^-32 回転 / 発射]
  掃引の先頭の点の番号
```

副情報は 56 bit/掃引、点あたり 0.068 bit（実測）。

点ごとに符号化するもの:

| 量 | 予測 | 実測の 0 次 |
|---|---|---|
| 面外のずれ | 0（面に乗るはず） | 3.501 bit |
| 面内の位置 | 走査モデル | 5.839 bit |
| z | 発射格子の左（掃引内の直前の発射） | 7.900 bit |

## 掃引の切り出し

固定周期 4.2330 ms では 68% の掃引しか薄くならない（位相ドリフト）。
符号器は**全点を扱わねばならない**ので、次のいずれかが要る。

1. 周期をドリフトさせる（$T(t) = T_0 + a t$）。パラメタ 2 つで済む
2. 掃引の境界を幾何から検出する（掃引内では面内座標 $s$ が単調）

薄くならない掃引が残った場合は、その掃引だけ**幾何v3 に落とす**。
恒等候補を必ず持つという原則をここでも使い、掃引単位で安全側に倒す。

## 検証

`pack` の往復検証（全列一致）と決定性（2 回書いてバイト一致）をそのまま使う。
通らなければ数字を出さない。
